# Chatbot

Chatbot con frontend en HTML/JS y backend en Python (Flask) que usa API de Gemini.

## Cómo correrlo

``` bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # y pon tu GEMINI_API_KEY dentro
python app.py
```

Abre http://127.0.0.1:8000
